Slanted spellings

  • Silent letters count for nothing: knife, comb, castle, wrist, calf.
  • gh is f (laugh = 58) or silent (night = 21).
  • ph is f: phone = 82.
  • x is k + s: box = 970. At the start it's z: xylophone = 0582.
  • ti, ci, ss, s can sound like sh/zh, which is 6: nation = 262, vision = 862.
  • ch can be k, which is 7: choir = 74, school = 075.
  • cc before e/i is k + s: accident = 70121.
  • dge is a single j: bridge = 946.
